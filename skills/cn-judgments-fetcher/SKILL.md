# 中国裁判文书检索 Skill

这个 skill 面向法学生案例检索。优先把自然语言请求映射成结构化检索参数，再调用 Playwright 脚本完成检索、摘要提取和下载链接抓取。

## 触发条件

- 用户要找某类中国裁判文书
- 用户用口语表达法律检索需求
- 用户希望直接得到案例摘要和下载链接
- 用户愿意在验证码或登录态阶段做人工接管

## 执行流程

1. 读取用户原始请求，保留原句。
2. 运行：

```bash
npm run chrome:start
npm run search -- "用户的自然语言检索请求"
```

推荐先运行 `npm run chrome:start`，让工具附加到用户自己已登录的本机 Chrome。这样最适合分发给不同同学使用，稳定性也优于完全由 Playwright 接管浏览器生命周期。

如果项目维护者明确要测试旧模式，再运行：

```bash
npm run search -- "用户的自然语言检索请求"
```

3. 直接返回脚本输出的 Markdown。
4. 如果状态是 `needs_human`：
   - 告诉用户浏览器已经打开，需要手动完成登录或验证码。
   - 提醒用户不要关闭浏览器窗口。
   - 完成后删除 `artifacts/human-in-the-loop.txt`，然后再次执行同一条命令。
5. 如果状态是 `blocked`：
   - 说明页面结构可能变化。
   - 让维护者更新 `config/selectors.example.json` 中的选择器后重试。

## 重要约束

- 不要在聊天里要求用户粘贴 Cookie、短信码或账号密码。
- 下载链接必须从已登录浏览器会话里抓取。
- 面向多人分发时，优先使用本机 Chrome + CDP 附加模式，不要分发固定 Cookie 或共享浏览器资料目录。
- 若页面出现验证码，优先人工接管；只有在用户明确允许且合规时才考虑外部打码平台。
- 如果结果不理想，先调整检索词、案由和法院层级，再重新执行，不要凭空编造案例。
