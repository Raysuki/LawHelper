# 人工接管与验证码

推荐默认策略：`manual`

原因：

- 裁判文书网存在动态验证码和登录态要求。
- 下载链接往往依赖已登录会话。
- 直接集成第三方打码平台会引入合规、隐私和稳定性风险。

人工接管流程：

1. Playwright 使用持久化用户目录启动浏览器。
2. 一旦检测到登录按钮或验证码元素，脚本进入等待状态。
3. 用户在浏览器中手动完成登录、滑块或图形验证码。
4. 用户删除 `artifacts/human-in-the-loop.txt`。
5. 脚本继续执行，并复用当前 Cookie / LocalStorage / SessionStorage。

如用户明确要求外部打码平台：

- 先确认法律与平台合规性。
- 明确告知账号、文书请求和页面截图可能涉及敏感信息。
- 除非用户明确批准并提供合规方案，否则不要默认接入。
